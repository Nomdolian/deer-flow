Trading system setup

Work down the page. Each section checks itself, so you can stop and come back — nothing here needs the command line.

Where things stand

Refreshes every few seconds.

    1  Your MT5 account

    The login number, password and server name from MetaTrader 5. The system attaches to your running terminal, so leave MT5 open and logged in.

    2  Database

    A single file on this computer. Nothing to install.

    3  What it's allowed to trade

    Search your broker's own symbol list — names differ between brokers, and picking from this list avoids the most common reason nothing ever trades.

    4  Prove it can place an order

    Places one minimum-size order on your demo account and closes it two seconds later. This is the step that catches broker mismatches — lot sizes, filling modes, stop distances — in one line instead of days later.

    It refuses to run unless MetaTrader 5 reports a demo account.

    Three processes. Start the API first if you want the phone app; the trading loop is the one that
    places orders.
    
    
    
    
    
    
    
  
    

  
    
    
    Before you use real money
    
    
    
      
        
    Stay on demo for weeksThe expectancy figures need roughly 20 closed trades per strategy before they mean anything.
    
        
    Re-run the backtestOn daily bars the strategies did not show an edge. Test them on your broker's 15-minute data before drawing conclusions.
    
        
    Check your broker's rulesSome prohibit automated trading and will close the account regardless of how the code behaves.
    
        
    Leave the risk defaults alone0.25% per trade, 3% portfolio cap. Raising them raises your risk of ruin non-linearly.
